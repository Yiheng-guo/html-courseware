# 教学与版式

## 逐页脚本

每页记录：标题、学员应理解或完成的动作、主要内容、例子或证据、建议版式。脚本用于制作，默认不嵌入面向学员的课件。

概念课可用：问题钩子 → 差异对比 → 原理 → 同案迭代 → 练习 → 边界与应用。
操作课可用：完成目标 → 示范 → 拆步骤 → 学员操作 → 常见失败 → 独立任务。
业务培训可用：业务场景 → 判断依据 → 工作流程 → 例外情况 → 情景演练。

## 同案递进

例如提示词课程可围绕同一个任务依次增加任务、角色、上下文、输出格式、示例。每次说明改了什么、为什么、结果差异。新增内容用绿色标出，并在序列第一页说明绿色含义；每一步严格累积，不悄悄删掉前面加的句子。若无实际模型输出，不把预期差异说成实测效果。原则不是固定五项，应按课程主题选取。

## 页面选择

- 封面：课程目标和受众能立即识别，标题短。
- 章节：说明即将回答的问题，帮助转换讲解节奏。
- 对比：相同尺度展示前后输入与结果，标出关键差异。
- 流程：显示因果、决策或步骤，不用装饰箭头代替逻辑。
- 案例：截图可放大，保留必要上下文；长 Prompt 可复制。
- 练习：给任务、约束、完成标准、建议分钟数和对照检查页。参考答案放下一页或可展开区域。
- 总结：给能带走的判断方法与下一步动作。

长内容优先合为一页内滚动，不拆成上、下两页；只有内容确实属于两个讲解点时才拆页；不一味缩小字号。素材优先清晰和相关；不为凑满每页添加图片。不要固定照搬参考课件的 52 页或其全部章节。
